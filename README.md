## 🧮 Калькулятор на C++

Простой консольный калькулятор с обработкой ошибок ввода и защитой от деления на ноль. Проект демонстрирует работу с потоками ввода/вывода (`iostream`) и базовую обработку исключений.

- **Язык:** C++17
- **Статус:** Завершен
- **Что внутри:** `main.cpp`, `README.md`, инструкция по сборке

👉 [Посмотреть код на GitHub](https://github.com/Maksimko-00/calculator-cpp)
