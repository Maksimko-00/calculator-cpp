# Калькулятор на C++

Консольный калькулятор с обработкой ошибок ввода и защитой от деления на ноль.

## Функционал
- Поддержка операций: `+`, `-`, `*`, `/`.
- Обработка некорректного ввода (если пользователь введет буквы вместо цифр).
- Проверка деления на ноль.
- Корректное отображение русского текста в консоли.
